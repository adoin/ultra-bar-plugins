# Schedule Calendar

## 地区与天气

日历右上角齿轮配置 IANA 时区、周一／周日起始、任务栏农历、天气地区和摄氏／华氏。任务栏可仅显示时间、时间天气并排、或每六秒轮播，点击仍展开日历；面板天气图标查看当前温度、体感、湿度、风速、来源和更新时间。

天气沿用 Codex Weather Widget 的服务选择：免 Key 的 Open-Meteo，或和风天气的专属 API Host 与 API Key；自动模式在和风不可用时回退 Open-Meteo。设置里提供和风项目与凭据申请指南。城市名会解析为完整地区路径；可使用“纬度,经度”精确指定。API Key 独立存入 Windows 凭据管理器，不写入配置或日志，留空保留已保存密钥。正常每30分钟更新，失败五分钟重试，可手动刷新；不自动定位，不请求时不访问网络。时钟摘要通过目录事件更新宿主，后台窗口关闭仍处理提醒和缓存。

数据来源：[Open-Meteo](https://open-meteo.com/)、[QWeather](https://www.qweather.com/)。Open-Meteo 数据按 CC BY 4.0 标注；和风使用当前天气接口及数据归因。

Ultra Bar 的时钟扩展插件。点击时间区域展开／收起日历；可从“设置 → 时钟扩展”切换入口。面板使用暗色毛玻璃、分级圆角、图标操作按钮和悬停名称，日期／时间输入保留原生控件行为。

## 日历与日程

- 42 格月历、公历日期、农历、春节／元宵／端午／七夕／中秋等节日；当前日、选中日、休息日与调休工作日标记。
- 今天、月视图、全部日程、已完成四个视图。月份箭头切换；选择日期查看日程，双击日期新建，双击日程编辑。
- 新建、编辑、删除、完成／取消完成，保存标题、地点、备注、通知链接、时长及全天状态。
- 六类发生规则：具体日期与时间、每个法定休息日、每个法定工作日、每年公历某日、每年农历某日（含闰月）、每天某时刻。
- 准时、提前 10 分钟、1 小时、1 天及自定义分钟的组合提醒；保留强制提醒、完成状态。处理提醒与完成日程是独立操作。
- 数据菜单支持导入／导出日程 JSON，及导入 `holiday-cn` 格式的节假日 JSON。导入日程补充新 ID，不覆盖已有日程。

日历导航、视图及 CRUD 操作均为图标按钮，悬停显示名称。编辑器使用同色毛玻璃、圆角输入卡片和保存／取消图标；高 DPI 可滚动表单，底部操作保持可见。更新原生面板时，已有编辑器或文件选择窗口未关闭就保留旧进程，避免丢失草稿；关闭后再次点击时间区域才安全替换为新版本。

## 数据和提醒

数据位置：`%LOCALAPPDATA%/UltraBar/plugins/schedule-calendar/calendar.json`。这是独立本地数据文件，支持重启后保留日程、提醒去重记录和待处理提醒；同一份数据只允许一个写入进程。保存通过临时文件原子替换，失败时保留旧内容。

插件后台随任务栏运行，关闭日历面板不停止提醒。普通提醒使用插件自己的原生浮窗，20 秒自动收起；强制提醒保留至“已处理”。通知链接只接受 HTTP(S)。当前不写入 Windows 通知中心历史，也不接入原软件的登录／云同步。

发生规则沿用原项目的 `Asia/Shanghai` 时区。任务栏时钟本身使用系统本地时间与用户格式设置。

内置 2025–2027 年的法定节假日与调休数据。其他年份可通过数据菜单导入，缺失时会提示该年调休数据未加载，并按周末回退计算。不会将回退结果伪装成已加载的法定安排。

## 开发和来源

在主程序仓库运行：

```powershell
pwsh.exe -NoLogo -NoProfile -File ./dev.ps1 -Task PluginBuild
pwsh.exe -NoLogo -NoProfile -File ./dev.ps1 -Task Test
```

`main.rn` 提供显示与视图配置，保存后自动重载。Rust 代码通过主程序 runner 以单任务、低优先级、CPU 上限构建，不另起无限制构建。

日历和模型代码来自本机 `D:/workspace/Schedule-Manager` 的 `src/calendar.rs` 和 `src/models.rs`（1.0.21，参考提交 `d75eb9e`）。保留的 MIT 许可见 `LICENSE.Schedule-Manager`。节假日来自 `NateScarlet/holiday-cn` 的 2025、2026、2027 JSON，许可见 `LICENSE.holiday-cn`。

`--smoke-test` 仅使用 `D:/tmp` 下的测试目录，渲染本插件的离屏窗口并校验六类原生表单规则，不发送鼠标或键盘输入。可用 `ULTRA_BAR_CALENDAR_SMOKE_DIR` 指定任务产物子目录，`ULTRA_BAR_CALENDAR_SMOKE_DPI` 检查 96–192 缩放布局。
